En este proyecto se utilizan estructuras de control para multiples verificaciónes, las cuales permiten controlar el comportamiento y desarrollo de la aplicación, permitiendo que la aplicacion dependiendo de la condicion que se cumpla haga una cosa o otra, para eso usamos el `if`, `else` y el `elseif`.

---

A continuación ejemplos de codigo de la aplicación con una breve explicación de cada una:
#Login | Url: https://github.com/Valentindg2506/Tinoprop/blob/main/V1.0.0-Produccion/login.php
---

```
	if (!empty($_SESSION['usuario'])) {
		header('Location: index.php');
		exit;
	}
```
Con ese `if` lo que hacemos en comprobar que la session de usuario no exista ya, es decir que si el usuario ya inicio sesion en un lapso corto de tiempo inicie sesion directamente, que no sea necesario iniciar sesion de nuevo.

```
    if ($email === '' || $password === '') {
        $mensaje = 'Completa email y contraseña.';
    } elseif (!validar_email($email)) {
        $mensaje = 'El correo no tiene un formato válido.';
    }
```
Este `if` se encarga de verificar que el campo contraseña y email no este vacio, en el caso de que este vacio saldran un mensaje de `Completa email y contraseña.`. En el caso de que esa condicion se cumpla pasa a la siguiente que se encarga de verifivcar que el correo tenga un formato valido.
